# synqora

Windows (Node 24): double-click `start-demo.cmd` and keep its window open. Close old demo windows on ports 4317/4173 first.
Double-click `reset-demo.cmd` to restore a clean CampusFest seed. See [DEMO.md](DEMO.md) and [BACKUP.md](BACKUP.md) for the presentation.

SYNQORA helps AI agents share plans, track requirement revisions, and flag outdated work for human review. Built by Team Git Happens for NexHack 2.0.

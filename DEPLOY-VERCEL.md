# Hosted SYNQORA
Deploy this branch, not main or the local integrated demo. Vercel requires a dedicated empty PostgreSQL database URL (DATABASE_URL), a strong operator password (SYNQORA_DEMO_PASSWORD, at least 16 characters), and server-only OPENROUTER_API_KEY and GEMINI_API_KEY for fresh model calls. Set SYNQORA_OPENROUTER_MODEL=baidu/ernie-5.5-flash-preview:free, SYNQORA_GEMINI_MODEL=gemini-3.5-flash-lite, SYNQORA_GEMINI_FREE_CONFIRMED=1 only for a billing-disabled Google project. Public GET workspace views are read-only and operator login protects writes. Do not store confidential data in this public demo. This initializes the CampusFest seed in an empty database; existing local results are NOT automatically copied. No simulated AI output. Do not paste credentials in chat or GitHub.
